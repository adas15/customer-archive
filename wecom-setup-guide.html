!配置前准备

只需 3 样东西，约 5 分钟完成。配置后所有员工立即可用，无需逐个安装。
  • 管理员权限：你是企业微信的「管理员」，或请管理员操作这一步。
  • 上面那串「侧边栏」链接：.../index.html?chatId=$CHAT_ID$（务必带 $CHAT_ID$ 变量，这是群隔离的关键）。
  • 可见范围：想让哪些员工/部门在侧边栏看到这个应用（配置时可勾选）。
提示：这个应用是纯网页，不需要上传任何安装包、不需要服务器。管理员只是在后台「登记一个网页地址」。

1登录企业微信管理后台

用管理员账号打开管理后台。

操作步骤

  1. 电脑浏览器打开 https://work.weixin.qq.com
  2. 点右上角「企业登录」，用企业微信 App 扫码 或账号密码登录。
  3. 登录后进入管理后台首页（左图所示布局）。
注意：必须是「管理员」身份登录，普通员工账号看不到左侧「客户联系」等配置菜单。

3找到「侧边栏」并添加网页

在「聊天工具」里点「进入 / 配置」，切到「侧边栏」Tab，添加自定义网页。

操作步骤

  1. 在「聊天工具」卡片点 「进入」或「配置」。

  3. 点 「添加」 → 选择 「配置网页」。
关键点：这里填的是网页地址，不是小程序、不是自建应用。选「配置网页」即可。

4填写名称与网页地址（核心）

这一步最重要：名称随便起，网页地址必须完整粘贴带 $CHAT_ID$ 的那条。

填写内容

  • 名称：填 客户档案库（员工在侧边栏看到的名字）。
  • 网页地址：粘贴下方蓝色框里的完整链接。
  • 图标（可选）：可上传一张 logo。

5设置可见范围并保存

选择哪些员工 / 部门能在侧边栏看到这个应用，然后保存。

操作步骤

  1. 在「可使用范围」里勾选员工或部门（如「销售部」「客服部」）。
  2. 确认网页地址无误后点 「保存」。
  3. 保存成功即生效，无需审批、无需发布。
范围建议：先选一个小范围（如试点部门）验证效果，没问题再全量放开。

6验证：员工侧边栏出现入口

配置完成后，员工在企微客户端（电脑 / 手机均可）打开任意客户或群聊，右侧栏即可看到「客户档案库」。

① 电脑端验证

打开一个客户 / 群聊 → 右侧「聊天侧边栏」点「客户档案库」→ 显示该群客户列表。切换不同群，数据随之隔离。

② 手机端验证

企微 App 打开会话 → 点右上角「···」或侧边栏图标 → 选「客户档案库」→ 同样可用，数据与电脑端各自本地存储。

③ 收集表闭环

在档案库点「↗ 收集表」复制链接发客户 → 客户填完导出 zip → 微信发回 → 档案库「导入」自动归群。

如果员工侧边栏看不到：① 确认该员工在「可见范围」内；② 让其退出企微重新登录刷新配置；③ 确认网页地址带了 $CHAT_ID$ 且企微已开通「客户联系」。
